## Description
**Dani: Mi Verdad** is an Interactive Visual Novel based on classic Mexican soap operas. Made with 3D Novel Engine, a tool built in Godot with Dialogic and VRM models.

## Instructions
**Play in full screen!**

### Movement
* WASD keys (Keyboard)
* Arrows (Keyboard)
* (WIP) Left joystick (Gamepad)

### Interaction
* X key (Keyboard)
* (WIP) Left action button (Gamepad)

### Camera (Third person)
* Mouse axes
* (WIP) Right joystick (Gamepad)

### Jump (WIP)
* Space bar (Keyboard)
* (WIP) Down action button (Gamepad)
